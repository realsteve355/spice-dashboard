Grok V8.3 Projection — MaryFontaine 20-year reference

Top-down implementation of Grok's stable simulation framework. Uses his Section 3 parameters to reproduce the projected trajectory.
What this is. A faithful reproduction of Grok's V8.3 projection using his exact Section 3 parameters and the Y0/Y5/Y12/Y20 data points from Sections 1-2. This is a top-down aggregate calculator, not an agent-based simulation — its purpose is to be the canonical reference trajectory the ABM (at /colony-v0) is being evaluated against. Trajectory anchors: Y0 81k employed (45%) / $1,350m profit; Y5 40k (22%) / $2,050m; Y12 27k (15%) / $2,680m; Y20 45k (25% voluntary) / $3,450m. Monthly values between anchor years are linearly interpolated. Charge = k × profit; UBI pool distributed equally to all 180k adults; tradable goods deflate -2%/yr; housing inflates +1.2%/yr.
